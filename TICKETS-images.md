## И-0 · Заплатка — ✅ 12.10.2026

`images.unoptimized: true` в `next.config.ts`: браузер берёт файл прямо
из бакета. Картинки видны, но тяжелее (до 1 МБ на файл). У заглушки
загрузки добавлен `onError` — если фото всё-таки не пришло, серая
плитка перестаёт мерцать.

## И-1 · Свои уменьшенные копии — ✅ 13.10.2026

Как устроено и почему так — [ARCHITECTURE.md](./ARCHITECTURE.md), §8,
«Свои уменьшенные копии». Коротко:

- новое фото — сервер режет 400/800/1200/1600 при загрузке
  (`lib/make-variants.ts`);
- старые — `scripts/make-image-variants.mjs` перед каждой сборкой
  основного сайта на Vercel, сам; вручную — `npm run make-image-variants`;
- сайт берёт копию под ширину (`lib/image-loader.ts`), заплатка И-0 снята.

**Что проверить на живом сайте после выкладки** (отсюда бакет недоступен):

1. В логе сборки на Vercel строка `[копии фото] готово: N, с ошибкой: 0`.
   Ошибки, если есть, перечислены там же по ключам.
2. Галерея и страница работы показывают картины; в DevTools → Network
   картинки с `.w400.webp` / `.w800.webp` в адресе, по 20–150 КБ.
3. Загрузить через админку новое фото — оно показывается; в бакете рядом
   с ним 4 файла `.w….webp`.

## И-2 · Vercel Pro — ждёт продажи

Включается вместе с продажей ([ARCHITECTURE.md](./ARCHITECTURE.md), §7):
по правилам Vercel тариф Hobby — для некоммерческих сайтов. После И-1
лимит обработки картинок для нас уже не важен.
