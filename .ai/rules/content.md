# Данные о работах и тексты

## Не выдумывать фактов

**Это главное правило раздела.** Страница работы — карточка товара, по ней
человек решает, покупать ли картину. Выдуманный размер холста или год —
обман покупателя, а не безобидная заглушка.

Нельзя придумывать:

- размеры холста,
- год создания,
- цену,
- технику, если она не видна однозначно,
- историю или описание работы.

Неизвестное поле оставляется пустым, а подпись собирается из того, что есть:

```ts
export function artworkCaption(work: DemoArtwork): string {
  return [work.medium, work.size].filter(Boolean).join(" · ");
}
```

Так карточка покажет «Холст, масло» вместо «Холст, масло · undefined»
и не соврёт про габариты.

## Что можно

- **Названия по виду работы** — можно, но пометить как требующие
  подтверждения художницы. Сейчас так проставлены все пять: «Башни в тумане»,
  «Башни на закате», «Дом с бирюзовыми ставнями», «Мост на закате»,
  «Ночной свет».
- **Тексты-рыба в вёрстке** — можно, пока нет настоящих. Помечать
  комментарием, чтобы не уехали в прод незамеченными.
- **Технику «Холст, масло»** — сейчас проставлена по виду мазка
  (мастихин, плотная фактура). Тоже требует подтверждения.

## Известные пробелы

Отслеживаются здесь, чтобы не потерялись:

- размеры всех холстов — неизвестны;
- годы создания — неизвестны;
- цены — решение «показывать публично или по запросу» не принято;
- настоящий email и телефон — в `lib/site.ts` стоит заглушка
  `hello@berlan-art.example`;
- текст «о художнице» для `/about` — нет.

Подтверждённый контакт один: Instagram **@art_berlant**.

## Тон текстов

Спокойный, без рекламных восклицаний. Художница пришла к живописи в 55 лет
и за несколько лет дошла до выставок — это сильная история сама по себе,
её не нужно усиливать превосходными степенями.
