# Данные о работах и тексты

## Не выдумывать фактов

**Это главное правило раздела.** Страница работы — карточка товара, по ней
человек решает, покупать ли картину. Выдуманный размер холста или год —
обман покупателя, а не безобидная заглушка.

Нельзя придумывать:

- размеры холста,
- год создания,
- цену,
- технику, если она не видна однозначно,
- историю или описание работы.

Неизвестное поле оставляется пустым, а подпись собирается из того, что есть:

```ts
// lib/artworks.ts
export function artworkCaption(work, lang = "ru"): string {
  return [artworkTechnique(work.technique, lang), artworkDimensions(work.dimensions, lang)]
    .filter(Boolean)
    .join(" · ");
}
```

Так карточка покажет «Холст, масло» вместо «Холст, масло · undefined»
и не соврёт про габариты.

## Что можно

- **Названия по виду работы** — можно, но пометить как требующие
  подтверждения художницы.
- **Тексты-рыба в вёрстке** — можно, пока нет настоящих. Помечать
  комментарием, чтобы не уехали в прод незамеченными.
- **Технику «Холст, масло»** — подтвердил заказчик 19 сентября 2026:
  у художницы она всегда одна. Поэтому в новой работе она подставлена
  по умолчанию (Э6-6), но поле можно исправить.
- **Год в новой работе** подставлен текущий — решение заказчика
  19 сентября 2026, отступление от правила выше, причина в
  [ARCHITECTURE.md](../../ARCHITECTURE.md). Заводя старую работу, год
  меняют вручную; при сдаче сайта напомнить об этом художнице.
- **Категорию** — только из списка `artworkCategories`
  (`lib/artwork-form.ts`), список утверждён заказчиком. Категория по сюжету
  на холсте — не выдумка: сюжет виден на репродукции.

## Известные пробелы

Отслеживаются здесь, чтобы не потерялись:

- размер холста не указан у 15 работ из 203, год — у 2, категория —
  у 10 (замер по базе 23.10.2026); пустые поля так и остаются пустыми,
  пока их не заполнит художница;
- цены — на сайте не показываются: продажа выключена 8 октября 2026 до
  платного тарифа Vercel ([ARCHITECTURE.md](../../ARCHITECTURE.md),
  раздел 7). В админке цену и статус заполнять можно, посетитель их не видит;
- почта — `NEXT_PUBLIC_CONTACT_EMAIL` задана 3 октября 2026 адресом заказчика,
  своей почты у художницы пока нет; телефон задан;
- текст «о художнице» для `/about` есть; правки художницы вносятся по её
  сообщениям (черновик — docs/o-hudozhnitse-chernovik.md).

- **написание имени латиницей** — «Berlant Dzhabrailova» поставлено по
  стандартной транслитерации, сверить с загранпаспортом художницы;
- английские тексты «о художнице» и политики — перевод русских, править
  вместе с ними; политику показать юристу.

Подтверждённый контакт один: Instagram **@art_berlant**.

## Тон текстов

Спокойный, без рекламных восклицаний. Художница пришла к живописи в 53 года
(уточнено заказчиком 8.10.2026) — это сильная история сама по себе, её не
нужно усиливать превосходными степенями. Признание, выставки и «место среди
художников» без названий, городов и дат не упоминать.
