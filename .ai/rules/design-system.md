# Дизайн-система

## Источник истины

| Что                       | Где                         |
| ------------------------- | --------------------------- |
| Исходные токены макета    | `design/tokens/organic.css` |
| Эталонные страницы макета | `design/mockups/*.dc.html`  |
| Рабочая версия в коде     | `app/globals.css`           |
| Живая витрина             | `/styleguide`               |

Макеты в `design/mockups/` **не трогать** — это эталон для сверки. Правки
идут в `app/globals.css`.

## Токены вместо значений

Цвета, радиусы и тени задаются **только токенами**. Произвольный hex
в разметке недопустим: он не переживёт смену палитры и разъедется с остальным
интерфейсом.

```tsx
// нет
<div className="bg-[#c67139]">

// да
<div className="bg-accent">
```

Палитра:

| Токен      | Значение  | Роль                                    |
| ---------- | --------- | --------------------------------------- |
| `bg`       | `#f5ead8` | фон светлых страниц                     |
| `surface`  | `#ebddc5` | карточки, поля ввода                    |
| `ink`      | `#201e1d` | текст                                   |
| `accent`   | `#c67139` | сиена: кнопки, ссылки, акценты          |
| `accent-2` | `#7a8a5e` | олива: второй акцент, статус «доступна» |

Плюс три тональных ряда по 9 шагов: `neutral-100…900`, `accent-100…900`,
`accent-2-100…900`. Один шаг любого ряда совпадает по светлоте с тем же шагом
остальных — они построены в OKLCH на общей шкале.

Радиусы названы по смыслу, а не по размеру: `rounded-pill` (кнопки, метки,
поля), `rounded-tile` (мелкие плитки), `rounded-card` (карточки),
`rounded-panel` (крупные панели).

## Приёмы оформления

- Чередование светлых секций и **тёмных полос** во всю ширину (`neutral-900`).
- **Тёплые радиальные свечения** по краям тёмных блоков.
- Крупные скругления у панелей, таблетки у кнопок и меток.
- Фильтр `.washed` на репродукциях — приглушает фото, чтобы живопись
  не спорила по насыщенности с охрой интерфейса.
- `.panel-dashed` — пунктирная рамка пустого состояния.
- `.bleed` — полоса во всю ширину окна внутри колонки с ограниченной шириной.

## Порядок работы

1. Новый компонент сначала появляется в `/styleguide`, потом уходит
   на страницу. Так видно все состояния сразу и не плодятся дубли.
2. Нужного варианта нет в системе — сначала добавить класс в `@layer
components` в `app/globals.css`, потом использовать.
3. **Отступление от макета — записать в [ARCHITECTURE.md](../../ARCHITECTURE.md)
   с причиной.**

Уже отступили — эти решения приняты, переигрывать их без нужды не надо:

| Отступление                                 | Причина                                                            |
| ------------------------------------------- | ------------------------------------------------------------------ |
| Literata + Manrope вместо шрифтов макета    | у шрифтов макета нет кириллицы                                     |
| Бургер-меню ниже 768px                      | в макете навигация занимала 148px на телефоне                      |
| Только 4 раздела в меню                     | «Выставки», «Магазин», «Блог», «Пресса» не в плане — вели бы в 404 |
| Фотография мольберта вместо CSS-конструкции | по просьбе заказчика                                               |
