# Дизайн-система

## Источник истины

| Что                       | Где                         |
| ------------------------- | --------------------------- |
| Исходные токены макета    | `design/tokens/organic.css` |
| Эталонные страницы макета | `design/mockups/*.dc.html`  |
| Рабочая версия в коде     | `app/globals.css`           |
| Живая витрина             | `/styleguide`               |

Макеты в `design/mockups/` **не трогать** — это эталон для сверки. Правки
идут в `app/globals.css`.

## Токены вместо значений

Цвета, радиусы и тени задаются **только токенами**. Произвольный hex
в разметке недопустим: он не переживёт смену палитры и разъедется с остальным
интерфейсом.

```tsx
// нет
<div className="bg-[#c67139]">

// да
<div className="bg-accent">
```

Палитра — **три зала**, они же темы. Цвет роли приходит из выбранного зала,
поэтому в разметке пишется только роль (`bg-bg`, `text-ink`, `bg-wall`),
а не оттенок:

| Токен      | Тёмный зал | Почти белый | Белый     | Роль                         |
| ---------- | ---------- | ----------- | --------- | ---------------------------- |
| `bg`       | `#131211`  | `#f6f5f3`   | `#ffffff` | фон страницы                 |
| `surface`  | `#1d1b1a`  | `#ecebe7`   | `#f3f3f2` | карточки, поля ввода         |
| `wall`     | `#0d0c0c`  | `#f0efec`   | `#ffffff` | стена коллажа, полосы, показ |
| `ink`      | `#f2f1ef`  | `#1b1a19`   | `#161616` | текст                        |
| `accent`   | `#c98a5e`  | `#8a5a3c`   | `#8a5a3c` | ссылки, надстрочники         |
| `accent-2` | `#8a9878`  | `#5b6b48`   | `#5b6b48` | статус «доступна»            |
| `btn`      | `#f2f1ef`  | `#1b1a19`   | `#161616` | главная кнопка               |

**В интерфейсе цвета нет.** Кнопки контрастны фону, а не залиты оранжевым:
на сайте живописи самым ярким пятном должна быть картина. Значения залов
лежат в `app/globals.css`, блок «залы»; переключатель — в шапке
(`components/ui/ThemeSwitch.tsx`), выбор хранится в браузере.

Тональные ряды по 9 шагов (`neutral-100…900`, `accent-100…900`,
`accent-2-100…900`) остались: они нужны меткам поверх фотографий, где фон
задаёт сама картина. В остальном интерфейсе — только роли.

Радиусы названы по смыслу, а не по размеру: `rounded-pill` (кнопки, метки,
поля), `rounded-tile` (мелкие плитки), `rounded-card` (карточки),
`rounded-panel` (крупные панели).

## Приёмы оформления

- Чередование светлых секций и **тёмных полос** во всю ширину (`neutral-900`).
- **Тёплые радиальные свечения** по краям тёмных блоков.
- Крупные скругления у панелей, таблетки у кнопок и меток.
- Фильтра `.washed` больше нет: он гасил живопись, чтобы она не спорила
  с охрой интерфейса, — а цвета в интерфейсе теперь нет вовсе. Картины
  показываются как есть.
- Полноэкранный показ работы зависит от зала: в тёмном фоном лежит размытая
  копия картины, в светлых — белая стена под верхним светом и тень под
  холстом.
- `.panel-dashed` — пунктирная рамка пустого состояния.
- `.bleed` — полоса во всю ширину окна внутри колонки с ограниченной шириной.

## Порядок работы

1. Новый компонент сначала появляется в `/styleguide`, потом уходит
   на страницу. Так видно все состояния сразу и не плодятся дубли.
2. Нужного варианта нет в системе — сначала добавить класс в `@layer
components` в `app/globals.css`, потом использовать.
3. **Отступление от макета — записать в [ARCHITECTURE.md](../../ARCHITECTURE.md)
   с причиной.**

Уже отступили — эти решения приняты, переигрывать их без нужды не надо:

| Отступление                                                    | Причина                                                               |
| -------------------------------------------------------------- | --------------------------------------------------------------------- |
| Literata + Manrope вместо шрифтов макета                       | у шрифтов макета нет кириллицы                                        |
| Бургер-меню ниже 768px                                         | в макете навигация занимала 148px на телефоне                         |
| Только 4 раздела в меню                                        | «Выставки», «Магазин», «Блог», «Пресса» не в плане — вели бы в 404    |
| Видео на фоне hero вместо мольберта с холстом                  | по просьбе заказчика; цикл «видео → слайды с работами → видео»        |
| Галерея — коллаж во весь экран, работа — картина во весь экран | по просьбе заказчика; в прежней вёрстке картина занимала треть экрана |
| Три нейтральных зала вместо палитры макета, `washed` удалён    | интерфейс был насыщеннее живописи; кнопка перебивала картины          |
