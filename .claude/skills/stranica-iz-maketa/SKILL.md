# Страница из макета

Порядок вёрстки страницы по эталону из `design/mockups/`. Цель — чтобы
страница совпадала с макетом по значениям, а не «примерно похоже».

## 1. Прочитать макет целиком

```bash
cat design/mockups/<Имя>.dc.html
```

Выписать перед началом:

- секции сверху вниз и их вертикальные отступы;
- какие классы дизайн-системы использованы (`.card`, `.tag`, `.btn`,
  `.panel-dashed`, `.washed`);
- какие цветовые токены (`--color-accent-2-100` и т.п.);
- где тёмные полосы во всю ширину, где светлые секции;
- поведение: сортировки, фильтры, лайтбоксы — они лежат в `<script
type="text/x-dc">` в конце файла.

## 2. Проверить, хватает ли дизайн-системы

Нужного класса нет в `app/globals.css` — **сначала добавить его**
в `@layer components` и показать в `/styleguide`, потом использовать
на странице. Не городить одноразовые стили в разметке.

Произвольный hex недопустим — только токены.

## 3. Разметка

- Хедер подключает сама страница: `<Header />` для внутренних,
  `<Header variant="overlay" />` для главной.
- Подвал не трогать, он в `app/layout.tsx`.
- Колонка контента — `<Container>`, у него уже max-width 1200px
  и «резиновые» поля из макета.
- Серверный компонент по умолчанию. `"use client"` — только если нужны
  состояние или обработчики.
- Секции с данными — через существующие примитивы `ArtworkImage`, `Tag`,
  `ButtonLink`.

## 4. Данные

До этапа 3 — из `lib/demo-artworks.ts`. После — из `lib/artworks.ts`.

**Не выдумывать поля, которых нет** (размеры холста, год, цена). Подпись
собирать через `artworkCaption`, чтобы пустые поля просто не выводились.

## 5. Метаданные

```tsx
export const metadata: Metadata = {
  title: "Название раздела",
  description: "Одно предложение о содержимом страницы",
};
```

Служебные страницы закрывать: `robots: { index: false, follow: false }`.

## 6. Проверить

```bash
npm run lint && npm run typecheck && npm run build
```

Затем **обязательно в браузере**:

- десктоп 1280px — общая композиция;
- мобильный 375px — горизонтальное переполнение должно быть 0;
- консоль на ошибки;
- ссылки ведут на существующие маршруты, а не в 404.

Проверить не удалось — сказать об этом прямо, не выдавать за сделанное.

## 7. Записать отступления

Отошли от макета — строкой в `ARCHITECTURE.md` с причиной. Отступления
бывают оправданными (мобильная навигация в макете занимала 148px), но
незаписанное отступление через неделю выглядит как ошибка.

## Осторожно

- В макете есть разделы, которых нет в плане: «Выставки», «Магазин»,
  «Блог», «Пресса». Ссылки на них дадут 404. Состав навигации —
  в `lib/site.ts`.
- Контакты в макете (`hello@berlan-art.example`) — заглушки.
  Подтверждённый контакт один: Instagram @art_berlant.
