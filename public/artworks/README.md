# Фотографии работ

Сюда кладутся снимки картин на время разработки, пока нет админки и
Cloudflare R2 (этапы 5–6). После их запуска изображения будут загружаться
через админку в R2, а эта папка исчезнет.

## Как добавить

1. Положить файл в эту папку. Имя — латиницей, строчными, через дефис:
   `bashni-v-gorah.jpg`, `podsolnuhi.jpg`, `piony.jpg`.
2. Вписать путь в `lib/demo-artworks.ts`, поле `src`:

```ts
{
  id: 1,
  title: "Башни в горах",
  medium: "Холст, масло",
  size: "70×90 см",
  status: "available",
  src: "/artworks/bashni-v-gorah.jpg",
}
```

Всё. Работы без `src` продолжают рисоваться цветной заглушкой — можно
добавлять фотографии по одной, ничего не ломая.

## Требования к снимкам

- Формат JPEG, длинная сторона 2000–2500px. Больше не нужно: на странице
  работы изображение показывается максимум в ~1200px, а вес страницы важнее.
- Кадрировать по краю холста, без стены и пола вокруг.
- Снимать при равномерном свете, без вспышки и бликов на масле.
- Не выкручивать насыщенность в редакторе: на сайте поверх наложен фильтр
  `washed`, который приглушает цвет — пересвеченный оригинал будет выглядеть
  грязным.
